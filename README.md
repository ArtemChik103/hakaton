# IT-Платформа

**🚀 Live Application (Vercel):** [https://frontend-nine-nu-59.vercel.app](https://frontend-nine-nu-59.vercel.app)

Веб-приложение для объединения IT-сообщества региона через удобный календарь событий, новости и систему мотивации.

## Особенности

- Календарь IT-мероприятий с фильтрацией по дате, тегам и формату (онлайн/офлайн)
- Лента новостей с анонсами и итогами событий
- Система достижений (ачивок) для мотивации участников и организаторов
- QR-коды для быстрой регистрации на офлайн-события
- Мультиплатформенная аутентификация (Email, SMS, Yandex OAuth)
- Адаптивный дизайн (мобильная и десктопная версии)
- Современный интерфейс пользователя с анимациями и интерактивными элементами
- Улучшенная страница профиля с информационными карточками и визуальными индикаторами
- Страницы FAQ, поддержки и условий использования

## Технологии

### Backend
- Python 3.10+
- Django 4.2
- Django REST Framework
- PostgreSQL
- Bcrypt для шифрования паролей
- JWT для аутентификации

### Frontend
- Vue.js 3
- Vuex для управления состоянием
- Vue Router для маршрутизации
- Tailwind CSS для стилей
- QRCode.js для генерации QR-кодов
- CSS анимации и переходы для улучшения пользовательского опыта

## Функциональность интерфейса

- **Профиль пользователя**: улучшенные карточки данных, визуальные индикаторы, анимированные переходы между вкладками
- **Навигация**: интуитивно понятное меню с иконками и визуальной обратной связью
- **Информационные страницы**: ответы на часто задаваемые вопросы, форма обратной связи, условия использования
- **Адаптивность**: оптимизированный дизайн для всех устройств от мобильных до десктопа
- **Модальные окна**: для редактирования информации и подтверждения действий
- **Редактор навыков**: интерактивный интерфейс для добавления профессиональных навыков с предложениями популярных тегов

## Установка

### Требования
- Python 3.10+
- Node.js 14+
- PostgreSQL 12+

### Настройка бэкенда

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/it_platform.git
cd it_platform
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

3. Установите зависимости:
```bash
cd backend
pip install -r requirements.txt
```

4. Создайте файл .env в директории backend/ с вашими настройками:
```
DEBUG=True
SECRET_KEY=your-secret-key-change-in-production
DB_NAME=it_platform
DB_USER=postgres
DB_PASSWORD=your-db-password
DB_HOST=localhost
DB_PORT=5432

# Yandex OAuth2 settings
SOCIAL_AUTH_YANDEX_OAUTH2_KEY=your-yandex-oauth2-key
SOCIAL_AUTH_YANDEX_OAUTH2_SECRET=your-yandex-oauth2-secret

# SMSC.ru settings
SMSC_LOGIN=your-smsc-login
SMSC_PASSWORD=your-smsc-password
```

5. Выполните миграции:
```bash
python manage.py migrate
```

6. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

7. Запустите сервер для разработки:
```bash
python manage.py runserver
```

### Настройка фронтенда

1. Перейдите в директорию frontend:
```bash
cd ../frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер для разработки:
```bash
npm run serve
```

4. Для сборки:
```bash
npm run build
```
